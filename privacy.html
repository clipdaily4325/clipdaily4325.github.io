Privacy Policy

Last updated: September 2026

1. Local-first by design

Shorts Studio runs entirely on the user's own computer. Videos, clips, transcripts and settings are stored locally on that computer. Shorts Studio operates no servers and collects no analytics or telemetry.

2. TikTok connection

If the user chooses to connect their TikTok account, Shorts Studio uses TikTok's official Login Kit and Content Posting API. The following data is involved:

  • An access token and refresh token, stored only in a local file on the user's computer, used to act on the user's behalf.
  • Basic profile information (display name), shown only inside the application so the user can see which account is connected.
  • Video files the user explicitly chooses to send, which are uploaded to the user's own TikTok drafts (inbox). Nothing is ever published automatically; the user reviews and publishes each video manually in the TikTok app.

3. What we do not do

  • No data is sold or shared with third parties.
  • No data is stored outside the user's own computer and the user's own TikTok account.
  • No advertising or tracking of any kind.

4. Revoking access

The user can disconnect TikTok at any time inside the application (which deletes the locally stored tokens) and can additionally revoke the app's access in their TikTok settings under "Security & permissions → Apps".

5. Contact

Questions about this policy can be sent to the developer via the contact details provided with the application.
