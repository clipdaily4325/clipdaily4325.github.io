1. What Shorts Studio is

Shorts Studio is a desktop application that runs locally on the user's own computer. It helps the user turn their long-form videos into short clips and, if the user connects their own TikTok account, send those clips to the user's own TikTok drafts (inbox). The user always reviews and publishes each video manually in the TikTok app.
